# Ishita Mishra portfolio

Static site: open index.html, or deploy this folder as-is.

Replace photo: overwrite assets/photo.jpg (4:5 portrait, ~900px wide).
Update resume: overwrite assets/resume/Ishita_Mishra_Resume.pdf (keep the filename).
Add/replace presentations: put the PDF in assets/presentations/ and edit the `pdf` path in the PROJECTS config near the bottom of index.html. For a .pptx, export to PDF first (PowerPoint: File > Export > PDF) so it embeds.
Add Figma / PRD links: set `prototype` and `extra` in PROJECTS. Buttons without a link show as disabled.
Deploy: drag the folder onto Netlify Drop or vercel.com/new, or push to GitHub and enable GitHub Pages.
